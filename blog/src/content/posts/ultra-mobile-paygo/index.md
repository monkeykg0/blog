Ultra Mobile PayGo 因为卡板和包装以紫色为主，国内通常叫它“美国紫卡”。它每 30 天只需 \$3，适合低频使用、接收美国短信验证码，或者长期保留一个真实的美国手机号码。

但它和英国 giffgaff 的保号逻辑完全不同：**PayGo 不是零月租，也不是偶尔发一条短信就能续期；必须保证每个 30 天周期都成功支付 \$3。** 这篇教程从买卡、激活、查余额一直讲到在中国大陆使用和长期保号。

:::note
本文依据 Ultra Mobile 官方页面整理，资料核验日期为 **2026 年 8 月 10 日**。套餐、资费和页面入口都可能调整，实际操作前请再查看[官方 PayGo 页面](https://www.ultramobile.com/paygo/)与[PayGo 条款](https://www.ultramobile.com/mobile-plans-terms-conditions/)。
:::

## 01 先看懂套餐与两种余额 💜

Ultra Mobile PayGo 当前每个 **30 天**周期包含：

| 项目 | 套餐内额度 | 用完后的美国境内资费 |
| --- | ---: | ---: |
| 通话 | 100 分钟 | \$0.03/分钟 |
| 短信 / MMS | 100 条 | \$0.01/条 |
| 5G / 4G LTE 流量 | 100MB | \$0.03/MB |
| 月费 | \$3/30 天 | 从 PayGo Wallet 扣除 |

套餐内的分钟、短信和流量会在本周期结束时到期，不会滚存。第 31 天进入一个新周期，因此续费日不一定是每月同一天。官方说明可见[PayGo 套餐介绍](https://www.ultramobile.com/paygo/)。

账户里会同时看到两类“余额”，不要混淆：

- **Plan Balance（套餐余量）**：本周期剩余的分钟、短信和流量。
- **PayGo Wallet（钱包余额）**：预存的话费。每周期的 \$3 月费、超出套餐后的用量、国际通话及蜂窝国际漫游费用会从这里扣除。

:::important
真正决定能否续费保号的是 **Wallet 里有没有足够的 \$3**，不是套餐里还剩多少分钟或流量。PayGo Wallet 上限为 **\$150**。
:::

## 02 买卡与激活前准备 🛒

### 购买正确的 PayGo 卡

官方目前只写明两种购买渠道：

1. [Ultra Mobile 官方 PayGo 页面](https://www.ultramobile.com/paygo/)跳转的 eBay 官方店。
2. 美国部分 T-Mobile 门店。

请认准 **Ultra Mobile PayGo** 套餐或包装，不要只凭“紫色 SIM 卡”判断。普通 Ultra Mobile SIM、Tourist SIM 和 PayGo SIM 的套餐及激活入口不同，买错后未必能选择 \$3 PayGo。

### 激活前检查清单

- 一台已解锁、支持 Ultra Mobile 网络和 VoLTE 的手机；可先用[官方兼容性检测](https://www.ultramobile.com/byop/)检查 IMEI。
- SIM 卡背面右上角的 **11 位 ACT CODE**，不要把它与 ICCID 混淆。
- 一个可正常接收邮件的邮箱。
- 获取新号码时需要一个美国 5 位 ZIP Code，系统会据此分配可用号码。
- 如需携号转网，准备原运营商的 Account Number、Transfer PIN / Passcode 和 Billing ZIP，并保持原号码有效，直到转入完成。
- 准备可用于充值的信用卡 / 借记卡，或 PayGo 专用充值卡。

:::warning
如果以后要在美国境外长期使用，最稳妥的做法是：**在美国境内完成激活、账户注册、Wi-Fi Calling 开通和收发测试后再离境。** 海外远程激活是否成功会受手机版本、运营商配置、网络环境等影响，官方并未保证所有境外场景都能完成首次配置。
:::

## 03 网页激活紫卡 🚀

网页激活既能申请新号码，也能携号转入，步骤如下：

1. 将 PayGo SIM 插入已解锁的手机，连接稳定的 Wi-Fi。
2. 打开[PayGo 官方激活页面](https://my.ultramobile.com/paygo/activation?lang=zh)。
3. 输入 SIM 卡背面右上角的 **11 位 ACT CODE**，点击 **Start or Resume your Activation**。
4. 选择获取新号码，或选择保留现有号码。
5. 获取新号码时，输入希望分配号码所在地的 5 位 ZIP Code，并按页面选择语言。
6. 携号转入时，准确填写原运营商的 Account Number、Transfer PIN / Passcode 和 Billing ZIP；在转入完成前不要主动注销原号码。
7. 按页面确认 PayGo 套餐、个人资料与付款信息，提交激活。
8. 收到激活完成提示后重启手机，关闭 Wi-Fi，测试拨号、短信和移动数据。

激活有问题时，可使用[官方在线聊天](https://www.ultramobile.com/chat/)，拨打 **1-888-777-0446**，或用已激活的 Ultra Mobile 手机拨 **611**。官方客服时间目前为每天太平洋时间 6:00–18:00。

## 04 用短信快速激活 📩

如果人在美国、手机已经连上 Ultra Mobile 网络，并且只需要一个新号码，可以用短信激活：

1. 插入 PayGo SIM 并开机。
2. 编辑短信 `GOGO 10001` 发送到 **6700**，将示例里的 `10001` 换成你需要的美国 5 位 ZIP Code。
3. 按回复短信继续操作，等待分配号码并完成激活。

:::note
短信方式只能获取新号码，**不能携号转入**。需要转入旧号码时请使用网页激活。
:::

## 05 注册账户与确认激活结果 👤

激活完成后，打开 [My Ultra Account](https://my.ultramobile.com/)：

1. 点击登录页面里的 **SMS a Password to My Device**。
2. 输入刚激活的 Ultra Mobile 手机号。
3. 输入短信收到的临时密码，再按提示创建自己的密码。
4. 登录后检查手机号、套餐到期日、套餐余量和 PayGo Wallet 余额。

随后做四项测试：

- 给另一个号码打一次电话。
- 发出并接收一条普通短信。
- 暂时关闭 Wi-Fi，测试移动数据。
- 打开飞行模式、重新打开 Wi-Fi，测试 Wi-Fi Calling 能否注册并收发短信。

如果只是忘了本机号码，可在账户首页查看，也可以给另一部手机拨号或发短信确认。不要只依赖手机“关于本机”里的号码字段，因为新卡激活后该字段可能不会立即刷新。

## 06 查询余额、用量与到期日 💰

### 方法一：短信查询（最快）

编辑短信 `BAL` 发送到 **6700**。回复通常会显示 PayGo Wallet、套餐剩余额度和当前周期到期日。

如只想查询数据用量，可发送 `DATA` 到 **6700**。

### 方法二：网页或 App 查询

- 网页登录：[my.ultramobile.com](https://my.ultramobile.com/)
- 手机端：Ultra Mobile App

账户首页可以查看当前方案、剩余分钟 / 短信 / 流量、Wallet 余额和续费日期。人在境外、短码短信发不出去时，网页查询最可靠。

:::tip
每次充值后再次发送 `BAL`，同时截图保存 Wallet 余额与到期日。遇到扣款争议时，这两项信息最有用。
:::

## 07 充值与自动续费 💳

PayGo 支持以下官方充值方式：

1. 登录 [My Ultra Account](https://my.ultramobile.com/)，使用信用卡或借记卡给 PayGo Wallet 充值。
2. 到 Ultra Mobile 授权零售商充值。
3. 在美国 T-Mobile 门店购买 **PayGo 专用** Recharge Card。
4. 联系客服 **1-888-777-0446**。

PayGo 专用充值卡目前有 **\$10、\$15、\$50** 三种面额。普通 Ultra Mobile Recharge Card 不一定适用于 PayGo，购买前必须确认卡面写明 PayGo。

### 方法一：网页手动充值

这是人在中国也最容易操作的方式：

1. 打开 [My Ultra Account](https://my.ultramobile.com/)并登录。
2. 进入 **Manage Balance、Wallet、Recharge** 或 **Billing Info**；网站改版时名称可能略有不同。
3. 选择给 **PayGo Wallet** 充值，不要误买 Data Pass、Voice & Text Pass 或 UpRoam。
4. 选择充值金额，填写信用卡 / 借记卡卡号、有效期、CVV 和账单地址。
5. 核对手机号和金额后提交付款。
6. 等待付款成功页面或确认邮件，再发送 `BAL` 到 **6700**，确认 Wallet 余额已经增加。

:::tip
如果银行卡被拒，不要连续快速重试，以免触发风控。先检查 Billing Address、卡片是否支持境外线上支付，再换一张卡或联系发卡行。
:::

### 方法二：PayGo 充值卡

1. 在美国 T-Mobile 门店或其他官方认可渠道购买 **PayGo Recharge Card**。
2. 刮开涂层取得充值 PIN。
3. 按卡面说明兑换；官方当前短信格式为 `RECHARGE 充值PIN`，发送到 **6700**。
4. 收到成功短信后，再发送 `BAL` 到 **6700** 核对 Wallet。

示例：充值 PIN 为 `1234567890` 时，短信内容写成：

```text
RECHARGE 1234567890
```

:::warning
PIN 只能使用一次，属于敏感信息。不要把完整 PIN、ACT CODE、ICCID 或短信验证码发给陌生代充商家。境外网络如无法发送 6700 短码，可登录账户按页面提示兑换，或联系官方客服。
:::

### 开启 Auto Renew

1. 登录 [My Ultra Account](https://my.ultramobile.com/)。
2. 在 **Billing Info** 添加信用卡或借记卡。
3. 打开 **Auto Renew On**。
4. 选择自动充值面额：官方当前提供 **\$5、\$10 或 \$20**。
5. 点击 **Save Settings**。

Auto Renew 会按设置给 PayGo Wallet 自动充值，每次续期所需的 \$3 再从 Wallet 扣除。自动充值的最低面额虽然是 \$5，但套餐价格仍是 \$3；未用于续费的金额会留在 Wallet，供后续续费或额外用量使用。

设置后请返回账户首页确认三项内容：

- **Auto Renew** 显示为 On。
- 绑定银行卡的末四位正确、有效期未过。
- Next Renewal / Expiration Date 与预期一致。

### 充值多少比较合适

- 临时补一次：Wallet 补到至少 **\$3**，确保下一周期能扣款。
- 保号 3 个周期：至少准备 **\$9**，建议多留一点余额应对短信或漫游扣费。
- 长期保号：开启 Auto Renew，同时保留至少 2 个周期的 Wallet 余额作为缓冲。

Wallet 中的钱也会支付超额用量和蜂窝漫游费。因此“充值够几个月”要以 `BAL` 显示的**实际余额**计算，不能只用累计充值金额除以 3。

:::warning
自动续费不是设置完就永远不用管。信用卡过期、风控拒付或账单地址不匹配都可能导致充值失败。建议每个周期到期前检查一次，并准备备用支付方式。
:::

## 08 长期保号规则 🛡️

PayGo 保号的核心只有一句话：**每个 30 天周期开始时，Wallet 必须成功扣除 \$3。**

推荐这样设置：

1. Wallet 至少预留能覆盖 2–3 个周期的金额。
2. 打开 Auto Renew，并保证绑定的银行卡有效。
3. 在手机日历建立每 **25 天**一次的循环提醒。
4. 收到扣款或续费短信后，用 `BAL` 查询新的到期日。
5. 邮箱和账户密码保持可用，开启 SIM Protect。

如果到期时无法付款，账户会被暂停，普通电话、短信和数据都不能使用。Ultra Mobile 的 PayGo FAQ 明确写明：**最后一次付款后 60 天仍未付款，账户和手机号码会被取消。** 号码取消后无法保证找回，因此不要把这 60 天当成正常保号周期，更不要等到最后几天才充值。

:::important
PayGo 的 1 个周期是 30 天，不是自然月。12 个周期只有 360 天；做年度预算和充值计划时，不要简单地把“每月 \$3”理解成每年永远只扣 12 次。
:::

## 09 在中国大陆使用与漫游资费 🌏

PayGo 支持国际漫游，但**不包含数据漫游**。语音、短信和 MMS 漫游费用直接从 PayGo Wallet 扣除。

Ultra Mobile 官方当前公布的中国大陆资费为：

| 项目 | 中国大陆蜂窝漫游资费 |
| --- | ---: |
| 通话 | \$3.59/分钟 |
| 发送短信 | \$0.50/条 |
| 接收短信 | \$0.10/条 |
| MMS | \$0.25/条 |
| 数据漫游 | PayGo 不提供 |

香港当前为通话 \$2.69/分钟，台湾为 \$2.39/分钟；两地短信和 MMS 价格与上表相同。资费随时可能调整，使用前应在[PayGo 国际漫游资费表](https://www.ultramobile.com/paygo/international-roaming/)再次搜索目的地。

为了避免误扣费：

- 在手机设置中关闭这张卡的**数据漫游**和**蜂窝数据切换**。
- 不需要蜂窝漫游时，可开启飞行模式后单独打开 Wi-Fi，使用 Wi-Fi Calling。
- 接收普通蜂窝短信也可能收费；不要反复请求验证码。
- 通话按分钟计费且价格高，除紧急情况外不建议通过蜂窝漫游接打电话。

:::warning
“能收到普通短信”不等于“所有平台验证码都能收到”。银行、支付平台和互联网服务会自行决定是否向预付费 / MVNO 号码发送验证码，Ultra Mobile 无法保证第三方 OTP 的送达。
:::

## 10 开启 Wi-Fi Calling 📶

Ultra Mobile 官方称所有套餐均支持 Wi-Fi Calling。它可以通过 Wi-Fi 使用原手机号拨打电话和收发短信，境外使用时不会产生蜂窝国际漫游费，但 PayGo 套餐本身仍只有 100 分钟和 100 条短信，不要把“免漫游费”理解成无限量。

### 开启前准备

- PayGo 号码处于 Active 状态，没有欠费或暂停。
- 手机已解锁，并且该型号 / 地区版本支持 VoLTE 与 Wi-Fi Calling。
- 手机系统和运营商设置已经更新。
- 有稳定的 Wi-Fi，以及一个真实、可确认的美国 E911 服务地址。
- 最好在美国境内、手机能正常连接 Ultra Mobile 蜂窝网络时首次开通。

### 第一步：在 Ultra Mobile 账户开通

1. 登录 [My Ultra Account](https://my.ultramobile.com/)。
2. 在账户设置或 Manage Plan 中找到 **Wi-Fi Calling & Text**。
3. 填写 E911 地址，包括门牌号、街道、城市、州和 ZIP Code。
4. 打开 Wi-Fi Calling & Text，保存设置。
5. 等待账户更新；如果页面找不到开关，可到授权门店办理，或联系客服 **1-888-777-0446**。

:::important
只打开手机里的 Wi-Fi Calling 开关还不够，**Ultra Mobile 账户侧也必须启用**。E911 地址用于美国紧急呼叫路由，应填写真实、准确的服务地址；地址改变后要及时更新。
:::

### 第二步：在 iPhone 开启

1. 设置 → 蜂窝网络 → 选择 Ultra Mobile 号码 → Wi-Fi 通话。部分 iOS 版本入口为“设置 → App → 电话 → Wi-Fi 通话”。
2. 打开“在此 iPhone 上进行 Wi-Fi 通话”。
3. 阅读提示并确认；如再次要求，填写或确认 E911 地址。
4. 返回“设置 → 通用 → 关于本机”，停留几十秒，安装可能出现的运营商设置更新。
5. 重启 iPhone，并连接稳定 Wi-Fi。

### 第三步：在 Android 开启

1. 设置 → 连接 / 网络和互联网。
2. 进入 SIM / 移动网络，选择 Ultra Mobile 号码。
3. 找到 **Wi-Fi Calling** 并打开。
4. 按提示填写或确认 E911 地址。
5. 如果可以选择偏好，设为 **Wi-Fi Preferred（优先使用 Wi-Fi）**。
6. 重启手机。不同品牌菜单名称不同，找不到时可直接在设置里搜索“Wi-Fi 通话”。

### 第四步：验证是否真的开启成功

不要只看开关，按下面的方法实际测试：

1. 打开飞行模式，确认蜂窝信号完全关闭。
2. 单独重新打开 Wi-Fi，并连接互联网。
3. 等待 30 秒至几分钟，观察状态栏或 SIM 状态是否出现 **Ultra Wi-Fi、Ultra Mobile Wi-Fi** 或类似字样。
4. 给一个普通美国手机号发送短信，并让对方回复。
5. 拨打一个普通美国号码，再让对方回拨。
6. 登录 My Ultra Account 查看用量变化，确认没有产生国际漫游扣费。

只要飞行模式下仍能用原号码收发普通短信和接打电话，才算验证成功。iMessage、FaceTime、WhatsApp 或微信能使用，并不能证明运营商 Wi-Fi Calling 已经注册。

### 境外使用时如何避免漫游费

- 只想通过 Wi-Fi Calling 使用时：保持飞行模式，单独打开 Wi-Fi。
- 需要保留蜂窝短信作为备用时：关闭数据漫游，同时保证 Wallet 有余额；中国大陆蜂窝接收短信当前为每条 \$0.10。
- Wi-Fi Calling 本身不收蜂窝国际漫游费，但通话和短信仍受 PayGo 的 100 分钟 / 100 条套餐额度及相应超额规则约束。
- 拨打非美国号码前先查国际通话资费，不要把“Wi-Fi Calling 免漫游”理解为拨打全球号码都免费。

详细说明见[官方 Wi-Fi Calling 指南](https://www.ultramobile.com/wifi-calling-text/)与[E911 披露](https://www.ultramobile.com/911-e911-disclosures/)。

:::note
Wi-Fi Calling 能否注册还取决于手机型号、地区版本、系统、SIM 配置和当前网络。官方虽然写明可在国际旅行时使用，但不保证每一个国家、Wi-Fi 网络和设备组合都能工作。长期在境外使用前，务必在美国境内完成开通和实际测试。
:::

### Wi-Fi Calling 开启失败怎么办

按以下顺序排查，每完成一步就重新开关飞行模式测试：

1. 确认账户为 Active，Wallet 足够支付续费。
2. 确认 Ultra 账户侧的 Wi-Fi Calling & Text 已开启，E911 地址已保存。
3. 更新手机系统和运营商设置，重启手机。
4. 关闭 Wi-Fi Calling，等待几分钟后重新开启。
5. 更换家庭或手机热点测试；公司、校园、酒店等 Wi-Fi 可能屏蔽相关连接。
6. Android 找不到开关时，核对具体型号是否支持 Ultra Mobile 的 Wi-Fi Calling 配置。
7. 联系客服，让客服检查号码侧的 Wi-Fi Calling provisioning（开通配置）。

不建议在号码只能依靠 Wi-Fi Calling 接码时随意重置网络、删除 eSIM 或发起换卡，因为重新配置可能需要短信验证或蜂窝网络。

## 11 美国境内无法上网或发 MMS 🧰

先重启手机并更新运营商设置。Android 如未自动生成 Ultra APN，可参考[官方 Android 设置](https://www.ultramobile.com/setup/android/)添加：

| 字段 | 内容 |
| --- | --- |
| Name | `Ultra` |
| APN | `Wholesale` |
| MMSC | `http://wholesale.mmsmvno.com/mms/wapenc` |
| MMS Port | `8080` |
| APN Type | `default,supl,mms,ia` |
| APN Protocol | `IPv4/IPv6` |
| APN Roaming Protocol | `IPv4/IPv6` |
| MVNO Type | `GID` |

其余未列字段保持空白或保留手机默认值，保存后选中该 APN 并重启。字段区分大小写；如果列表中已经有 **Ultra (wholesale)**，直接选中即可，不要重复创建。

iPhone 通常会自动下发运营商配置，可进入“设置 → 通用 → 关于本机”等待更新提示。仍有问题时参考[官方 iPhone 设置](https://www.ultramobile.com/setup/iphone/)。

## 12 常见问题排查 🧩

### `BAL` 发到 6700 没有回复

- 确认号码未暂停，且手机能够发送普通短信。
- 境外蜂窝网络可能不支持美国短码，改用网页或 App 查询。
- 关闭并重新开启飞行模式，手动尝试其他可用漫游网络。

### 到期日还有时间，为什么不能用

- 检查的是 Plan Balance 还是 Wallet Balance。
- 套餐额度可能已经用完，而 Wallet 又没有余额支付超额用量。
- Voice / Data Pass 只对状态正常的账户有效，暂停账户无法使用。

### Wi-Fi Calling 开关不存在或一直无法注册

- 确认手机已解锁并支持 VoLTE、Wi-Fi Calling。
- 更新系统与运营商设置，重新插卡并重启。
- 确认 Ultra 账户侧也已打开 Wi-Fi Calling & Text，并填写 E911 地址。
- 更换稳定的 Wi-Fi 测试；公共 Wi-Fi 可能阻止相关网络连接。
- 仍失败时联系官方客服，不建议反复重置 eSIM / 换卡，以免号码暂时失联。

### 自动续费失败

- 更新过期银行卡和 Billing Address。
- 手动充值后，用 `BAL` 确认 Wallet 已到账。
- 在到期日前处理，不要依赖号码注销前的宽限时间。

## 13 账户安全与换机建议 🔐

- 在账户的 **Password & Security** 中打开 **SIM Protect**，降低号码被恶意转出或补卡的风险。
- 保存手机号、ACT CODE、ICCID、账户邮箱、续费日和客服工单号，但不要公开这些信息。
- 不要把短信验证码、账户密码或 Transfer PIN 发给代充商家。
- 换机前先确认新手机兼容；换实体 SIM 或转 eSIM 前，确保账户能登录并能接收验证码。
- 不要只把一个高价值账户的找回方式绑定在这张卡上，最好同时保留邮箱、安全密钥或备用号码。

## 14 一页式保号清单 ✅

每个周期只需要检查下面几项：

1. 发送 `BAL` 到 **6700**，确认下次到期日。
2. 确认 PayGo Wallet 至少有 **\$3**，最好预留 2–3 个周期。
3. 确认 Auto Renew 已开启、银行卡未过期。
4. 测试一次短信接收，确认号码状态正常。
5. 检查邮箱里是否有付款失败或账户提醒。
6. 更新日历中的下一次检查日期。
